# Быстрый старт

## Шаг 1: Установка зависимостей

```bash
npm install
```

## Шаг 2: Запуск в режиме разработки

### Вариант А: Без SSR (быстрее для разработки)

```bash
npm start
```

Откройте http://localhost:4200

### Вариант Б: С SSR

```bash
npm run dev:ssr
```

Откройте http://localhost:4000

## Шаг 3: Изучите примеры

После запуска, перейдите по ссылкам в навигации:

1. **Home** - Обзор возможностей SSR
2. **Transfer State** - Передача данных без повторных запросов
3. **Platform Check** - Проверка, где выполняется код (сервер/браузер)
4. **SEO** - Мета-теги для поисковой оптимизации

## Проверка SSR

### Просмотр серверного HTML

Откройте исходный код страницы (правый клик → "Просмотр кода страницы" или Ctrl+U).

Вы должны увидеть:
- Полностью отрендеренный HTML с данными
- Тег `<script id="transfer-state">` с данными
- Мета-теги в `<head>`

### Отключите JavaScript

1. Откройте DevTools (F12)
2. Settings (F1) → Debugger → Disable JavaScript
3. Обновите страницу (F5)

Вы должны увидеть контент, даже без JavaScript! Это и есть SSR в действии.

## Проблемы?

### Ошибка при установке

```bash
rm -rf node_modules package-lock.json
npm install
```

### Порт уже занят

Измените порт в `server.ts`:

```typescript
const port = process.env['PORT'] || 4000; // Измените 4000 на другой порт
```
