## 💡 Ключевые концепции

### Transfer State
Избегайте повторных HTTP запросов:
- На сервере: загружаем данные и сохраняем
- Клиент: берет из кеша, не делает запрос

### Platform Check
Разный код для сервера и браузера:
- `isPlatformBrowser()` → window, localStorage работают
- `isPlatformServer()` → серверная логика

### SEO Meta Tags
Мета-теги для поисковиков:
- Title, Description
- Open Graph (Facebook, LinkedIn)
- Twitter Cards

### Hydration
Angular "оживляет" серверный HTML:
- Не перерисовывает весь DOM
- Прикрепляет обработчики событий
- Делает страницу интерактивной

## ❓ Часто задаваемые вопросы

**Q: Нужно ли устанавливать что-то кроме npm?**
A: Нет, только Node.js и npm.

**Q: Как запустить без SSR для сравнения?**
A: `npm start` - запустит обычную версию на http://localhost:4200

**Q: Где увидеть разницу между SSR и без SSR?**
A: Откройте исходный код (Ctrl+U). С SSR - полный HTML, без SSR - пустой <app-root>.

**Q: Можно ли использовать этот код в своем проекте?**
A: Да! Код создан для обучения, используйте свободно.
